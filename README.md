# BMW Showcase Site - Innovacion y Rendimiento Aleman

Este proyecto es una pagina web profesional dedicada a los coches BMW, enfocada en un disen~o moderno, elegancia y alto rendimiento.

## 🚀 Caracteristicas
- **Disen~o Moderno:** Estetica inspirada en BMW con una paleta de colores azul oscuro, blanco y gris metalico.
- **Responsivo:** Totalmente compatible con dispositivos moviles y de escritorio.
- **Secciones Detalladas:**
  - **Inicio:** Introduccion impactante.
  - **Modelos:** Fichas tecnicas de modelos iconicos como Serie 3, Serie 5, X5 e i8.
  - **Historia:** Linea de tiempo interactiva sobre la evolucion de la marca.
  - **Innovacion:** Enfoque en vehiculos electricos (BMW i) y conduccion autonoma.
  - **Contacto:** Formulario funcional con validacion en JavaScript.
- **Animaciones Suaves:** Efectos de fade-in y slide-up al desplazarse.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estructura semantica.
- **CSS3:** Estilos personalizados, Flexbox, Grid y animaciones.
- **JavaScript (Vanilla):** Interactividad, validacion de formularios y manejo del menu movil.

## 📥 Instalacion y Uso
1. Clona este repositorio:
   ```bash
   git clone https://github.com/comarni/bmw-showcase-site.git
   ```
2. Abre el archivo `index.html` en tu navegador preferido.
